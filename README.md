# Meme Deck

[Open the soundboard](https://chatgptricks.github.io/meme-deck-pages/)

128 real MP3 clips with offline playback in one classic Braun-inspired layout, including 16 first-minute Betty la Fea songs and character themes. Warm ivory, clear controls and tactile pads fill the screen on iPhone and desktop.

On iPhone, open the site in Safari and use Share → Add to Home Screen. Open once online and wait for OFFLINE READY to save all 128 bundled clips. Every pad then plays directly without a video player or an internet connection.

This repository contains only the published app. Original source links, including each Betty recording's YouTube URL, are retained in the sound library and sounds.json. Recordings belong to their respective rights holders.
